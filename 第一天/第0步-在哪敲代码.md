# 第 0 步:代码写在哪、怎么运行(从零开始)

## 先理解两个东西

1. **编辑器**:用来"写"代码的地方。你现在用的 VS Code 就是。代码是普通文本,保存成以 `.swift` 结尾的文件。
2. **终端(Terminal)**:用来"运行"代码的地方。你在里面输入命令,电脑执行。

流程永远是两步:**在编辑器里写文件 → 在终端里运行文件**。

## 第 1 步:打开终端

在 VS Code 里:

- 菜单栏点 **终端 → 新建终端**(英文界面是 Terminal → New Terminal)
- 或者按快捷键 `` Ctrl + ` ``(Ctrl 加键盘左上角 1 左边那个键)

VS Code 窗口下半部分会出现一个黑框(或白框),光标闪烁,这就是终端。

## 第 2 步:进入项目文件夹

在终端里输入下面这行,按回车:

```bash
cd ~/Projects/ios/第一天
```

`cd` 的意思是 "进入这个文件夹"。输入 `ls` 回车,你会看到文件列表,里面有 `day1.swift`。

## 第 3 步:运行现成的示范代码

```bash
swift day1.swift
```

你会看到一堆输出(`Hello, Swift!` 等)。**能看到这些,说明环境没问题。**

## 第 4 步:自己新建一个文件并运行

1. 在 VS Code 左侧文件列表里,右键 `第一天` 文件夹 → **新建文件**
2. 文件名输入 `hello.swift`,回车
3. 在打开的空白文件里敲(自己敲,别复制):
   ```swift
   print("Hello, Swift!")
   ```
4. 按 `Cmd + S` **保存**(不保存的话运行的是旧内容,这是新手最常见的坑)
5. 回到终端,输入:
   ```bash
   swift hello.swift
   ```
6. 看到 `Hello, Swift!` 就成功了。

之后每次的循环就是:**改代码 → Cmd+S 保存 → 终端运行 `swift 文件名.swift`**。

## 常见问题

| 现象 | 原因 / 办法 |
|---|---|
| `command not found: swift` | 没装 Swift。告诉我,我帮你查 |
| `no such file or directory` | 不在正确的文件夹。重做第 2 步;用 `pwd` 看当前位置 |
| 改了代码但输出没变 | 忘了保存(Cmd+S) |
| 终端按上箭头 `↑` | 会出现上一条命令,不用重复敲 |
| 想中断正在运行的程序 | 按 `Ctrl + C` |
